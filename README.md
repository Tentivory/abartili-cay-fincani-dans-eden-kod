# 🍵 Abartılı Çay Fincanı Dans Ettiren Kod

## Bu Ne Lan?

Dünyanın **en ciddi** çay fincanı dans ettirme algoritmasıdır.  
Gerçekten çalışır. Terminalde fincan dans eder. Hayatınız değişir.

### Nasıl Çalıştırılır?

```bash
python cay_fincani_dansettir.py
```

İşte bu kadar. Daha basit bir şey yok. Daha absürt bir şey de yok.

## Neden Bu Repo Var?

Çünkü birileri "durduk yere aklına bir şey takıldı, repo aç" dedi.  
Takıldı. Açtık. Dans ettirdik.

## Özellikler

- Gerçekten çalışır (Python 3+)
- Fincan dans eder
- Çay içilmiş gibi hissettirir
- Hiçbir şey üretmez ama mutluluk üretir

## Lisans

Özgürce kullan, abart, dans ettir.  
Ama fincanı kırma.
